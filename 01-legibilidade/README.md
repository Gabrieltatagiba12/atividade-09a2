# Legibilidade

## Problema no código ruim
Nomes de variáveis e funções não são claros, dificultando o entendimento.

## Por que o código bom é melhor
Utiliza nomes significativos e organização, facilitando a leitura e manutenção.

## O que foi aplicado
Nomes claros, função bem definida e separação de responsabilidades.
