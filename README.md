**Linguagem escolhida:** JavaScript (Node.js)

## Sobre Qualidade de Código
Qualidade de código é fundamental para garantir que sistemas sejam fáceis de entender, manter, escalar e testar. Um código de qualidade segue boas práticas, padrões, é bem documentado, seguro e eficiente.

## Estrutura do Projeto
Cada pasta aborda um critério de qualidade, contendo exemplos de código ruim e bom, além de um README explicativo.

```
/exercicio-qualidade-codigo
  /01-legibilidade
  /02-documentacao
  /03-padronizacao
  /04-reutilizacao
  /05-manutenibilidade
  /06-robustez
  /07-testabilidade
  /08-eficiencia
  /09-escalabilidade
  /10-seguranca
README.md
```

## Como Executar os Exemplos
1. Instale o Node.js.
2. Navegue até a pasta do critério desejado.
3. Execute o arquivo ruim.js ou bom.js:
   ```
   node ruim.js
   node bom.js
   ```

## Objetivo
Comparar exemplos de código ruim e bom para cada critério de qualidade, mostrando como aplicar boas práticas em JavaScript/Node.js.
