# Padronização

## Problema no código ruim
Não segue padrões da linguagem, dificultando colaboração e manutenção.

## Por que o código bom é melhor
Segue padrões de estilo e boas práticas, facilitando o trabalho em equipe.

## O que foi aplicado
Uso de const, funções nomeadas e padrão de estilo.
